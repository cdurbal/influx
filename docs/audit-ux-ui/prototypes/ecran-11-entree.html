Écran 11 · Annonceur, créateur

Inscription et connexion

Une colonne étroite, un sujet par écran : la porte, l'e-mail, le code, puis les informations (inscription seulement). Le rôle n'est dit qu'une fois, le code passe à quatre blocs, les informations se rangent en deux groupes titrés (C12), et l'écran « compte créé » disparaît : on arrive directement sur l'accueil de première visite (écran 1). Choix du 2026-11-24 : un seul écran d'informations, pas d'écran « compte créé », code en six cases sur un seul champ.

U47U48U62U25U26U63

À essayer en plein écran : tout le parcours depuis la porte ; une adresse mal formée (l'erreur s'efface dès la frappe) ; coller un code de six chiffres (le sixième l'envoie) ; « Je ne reçois pas le code » ; « Créer mon compte » avec des cases vides, puis les liens du résumé.

1Problèmes relevés

  • « Étape 1 sur 3 » pour une connexion en deux écrans, et un écran « Votre compte est créé » qui impose un clic de plus (U47).
  • Le rôle dit deux fois sur l'écran e-mail, et 8 blocs sur l'écran du code (U48).
  • Trois sujets sur l'écran des informations, l'attestation de majorité loin des deux autres engagements (U62).
  • Une erreur qui reste affichée jusqu'au clic suivant (U25), une liste des manques inerte (U26), et « Valider » pour le code (U63).

3À valider par vous

  • Le parcours entier, sur téléphone d'abord, puis sur ordinateur.
  • Les textes juridiques (notice sur l'adresse, consentement, CGU) reprennent ceux de l'écran actuel : seule leur place change.
  • Les six cases sur un seul champ existent déjà en production : le prototype les garde, en ajoutant le bord d'erreur et l'effacement à la frappe.
