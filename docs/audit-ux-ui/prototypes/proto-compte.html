Supprimer mon compte

La suppression de votre compte est définitive. Elle ne peut pas être annulée. Vous serez déconnecté de tous vos appareils. Téléchargez d'abord votre export : il sera effacé avec votre compte.

Ce qui disparaît

  • Vos informations de compte : adresse e-mail, pays, langue, statut ou nom d'entreprise.
  • Votre contact chez Brevo et chez Apollo.io : la suppression leur est transmise en priorité.
  • Votre accès : vous ne pourrez plus vous connecter.

Ce qui est conservé, et pourquoi

  • Les e-mails déjà envoyés : nous ne pouvons pas les rappeler.
  • Les écritures du journal d'activité, sous une forme qui ne vous nomme plus.
  • La trace de votre acceptation des conditions d'utilisation, sous une forme qui ne vous nomme plus.

Tapez SUPPRIMER, en capitales, pour confirmer.

Un code de vérification vous sera ensuite demandé.
