Micro-interactions

Un mouvement a un seul rôle : retour, continuité ou hiérarchie. Il n'anime que l'opacité, la position, l'échelle et les couleurs, avec les durées et les courbes des tokens, et disparaît sous « réduire les animations ». Aucune bibliothèque : CSS natif (transition, @starting-style, position: sticky).
