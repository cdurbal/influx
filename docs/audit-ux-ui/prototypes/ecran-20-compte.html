Mon compte

Les quatre pages du Compte (Mes informations, Mes préférences, Mes sessions, Mes données), une par sujet, sur une colonne étroite et sans carte dans la carte ; sur téléphone, la page-menu « Mon compte » (D74). Le changement d'adresse contrôle la nouvelle adresse avant tout code (U33) et montre ses trois étapes ; « Mes informations » s'enregistre au fil de la saisie, comme les profils, et renvoie au profil de marque pour le nom public (U51).

U33U51U63

À essayer en plein écran : « Continuer » avec l'adresse mal formée, puis avec l'adresse actuelle, puis avec une bonne adresse ; « Confirmer ce code » ; « Retirer mon consentement » ; fermer une session ; « Supprimer mon compte » sans le mot, puis avec.

1Problèmes relevés

  • La nouvelle adresse part sans contrôle local, et un refus consomme le « code frais » : une faute de frappe coûte un nouveau parcours de codes (U33).
  • Le nom de l'entreprise se modifie à deux endroits, avec deux modèles d'enregistrement : automatique dans le profil, bouton dans « Mes informations » (U51).
  • « Valider ce code » ne dit pas ce qui se passe (U63).

2Composition cible

PageContenu
Mon compte (téléphone)Page-menu : profil de marque, Mes informations, Mes préférences, Mes sessions, Mes données, chacun avec sa ligne d'explication ; « Se déconnecter »
Mes informations« Votre compte » enregistré au fil de la saisie (nom de l'entreprise, pays, langue, statut) ; le nom de l'entreprise est la raison sociale, le nom public renvoie au profil de marque. « Adresse e-mail de connexion » : l'adresse actuelle, « Changer d'adresse », puis trois étapes visibles (nouvelle adresse contrôlée ici, confirmation d'identité, les deux codes) ; « Confirmer ce code »
Mes préférencesUn seul sujet, son état et son origine, un bouton qui dit ce qu'il fait (retirer ou recevoir de nouveau) ; « Ce que le retrait ne change pas »
Mes sessionsUne ligne par navigateur, « Cet appareil » marqué, « Fermer » sur les autres ; « Fermer toutes les sessions » replié
Mes donnéesVos demandes, l'export, puis « Supprimer mon compte » replié : ce qui disparaît, ce qui est conservé et pourquoi, le mot SUPPRIMER, puis un code

Les textes reprennent ceux du produit actuel (account.json), sauf « Confirmer ce code » et la phrase sur le contrôle de l'adresse.

3À valider par vous

  • Les pages, sur ordinateur et sur téléphone.
  • L'ordre du changement d'adresse : la nouvelle adresse est saisie et contrôlée avant la confirmation d'identité, pour qu'un refus ne consomme pas le code. L'étape de confirmation d'identité (écran du code de l'écran 11) est simulée.
  • Un seul endroit pour la raison sociale (« Mes informations ») et un seul pour le nom public (profil de marque) : si c'est aujourd'hui le même champ en base, la séparation est à arbitrer par le product-owner.
