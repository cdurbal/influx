# PL-03 — `fix(health): cached status for /health and unverified browser errors`

Grille `dev-react-node`, puis celle d'`expert-cybersecurite` pour J9S-7.

**Lire :** `archives/jalons/j9-fiche.md` l. 36-37 ; `apps/web/src/app/health/route.ts` ;
`apps/backoffice/src/components/HealthErrors.tsx` (rendu d'une erreur de source navigateur).

**Livrer :**
- **J9S-6** : la route `/health` de `apps/web` garde en mémoire du processus le résultat de
  `GET /v1/status` pendant 5 s (succès comme échec) ; un flot ne consomme plus le seau de
  `/v1/status` ; réponse `200` ou `503` à corps vide inchangée (EC-22).
- **J9S-7** : sur « Santé technique », un message d'erreur de source navigateur est présenté comme
  « source navigateur, texte non vérifié », en texte brut, jamais cliquable ni interprété (aucun
  lien, aucun `href`, aucun HTML) ; libellé ajouté à `apps/backoffice/src/messages/fr.ts`.

**Prouver :** un test unitaire par point (cache : deux appels en moins de 5 s donnent un seul appel
amont ; au-delà, un nouvel appel ; texte : une URL et du balisage restent du texte) ; spec e2e de
l'écran Santé ; `pnpm check:fast`.

**Arrêt si :** le cache exige un état partagé entre instances (le noter, ne pas l'ajouter).
