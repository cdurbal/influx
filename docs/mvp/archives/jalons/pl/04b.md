# PL-04b — `fix(api): test:db runs only the files it is given`

Grille `testeur`. Ajoutée par l'arrêt de PL-04 (choix A du fondateur, 2026-10-31).

**Lire :** `apps/api/package.json` (`test:db`) ; `apps/api/scripts/check-case-floors.ts` ;
`CLAUDE.md` §7 règle 5 (déjà dans ton contexte) ; les scripts `test*` de `apps/web` et
`apps/backoffice` (même forme `… && node scripts/check-case-floors.ts`).

**Constat (PL-04) :** `pnpm --filter @influx/api test:db -- <fichier> --reporter=dot`, commande
prescrite par `CLAUDE.md` §7, lance toute la suite base (environ 255 s) : pnpm ajoute les arguments
après le `&&`, donc au contrôle des planchers et non à vitest.

**Livrer :**
- La commande de `CLAUDE.md` §7 règle 5 fait ce qu'elle dit : avec des fichiers, vitest ne lance
  qu'eux ; sans argument, comportement actuel exact (toute la suite, rapport JSON, contrôle des
  planchers). Forme libre (petit script Node sans build, syntaxe effaçable) ; aucune dépendance.
- Lancement filtré : planchers contrôlés pour les seuls fichiers lancés, ou contrôle sauté avec une
  ligne qui le dit ; jamais un plancher baissé, jamais un contrôle affaibli sur la suite complète.
- Même défaut ailleurs (scripts `test*` des fronts, `test:artifacts`) : même correctif, ou noté
  dans la réponse s'il n'est pas sur un chemin prescrit.
- La CI garde ses commandes actuelles (sans argument).

**Ne pas toucher :** le travail non commité de PL-04 dans l'arbre (voir `04a.md`) ; `CLAUDE.md`
sauf si la commande prescrite doit changer de forme.

**Prouver :** `pnpm --filter @influx/api test:db -- db-tests/t8-verify-code.test.ts --reporter=dot`
ne lance que ce fichier (durée relevée) ; `pnpm --filter @influx/api test:db` sans argument lance
la suite et le contrôle des planchers comme avant ; `pnpm check:fast`.

**Arrêt si :** le correctif exige de changer un job de CI.
