# PL-01a — `fix(web): keep the language hand-over draft when React restarts a render`

Grille `dev-react-node`. Ajoutée par l'arrêt de PL-01 (choix A du fondateur, 2026-10-31) : seule
exception à l'invariant 1 avec PL-03.

**Lire :** `apps/web/src/components/auth/AuthFlow.tsx` l. 70-110 ; `apps/web/src/components/auth/journey-memory.ts`
(en-tête « never while rendering », `takeForLocale`) ; `apps/web/e2e/journey-resume.spec.ts` l. 90-130.

**Constat (trace de PL-01) :** sous charge (2 workers), après le passage de l'anglais au français
en navigation douce, le formulaire revient vide et `GET /api/v1/auth/journey` part : `handedOver`
vaut `null`. `takeForLocale(locale)`, appelé dans l'initialiseur d'un `useState`, vide la variable
du module en la lisant ; un rendu abandonné puis relancé la trouve vide.

**Livrer :**
- Plus aucun effet de bord pendant le rendu : lecture **sans vidage** pendant le rendu (idempotente),
  vidage dans un effet après le montage ; le premier rendu du formulaire reste prérempli (aucun
  passage vide puis plein). Toute autre solution garde ces deux propriétés.
- En-tête de `journey-memory.ts` conforme au code.
- Tests unitaires du module (lieu des tests unitaires existants de `apps/web`) : deux lectures
  avant le vidage rendent le même brouillon ; après le vidage, plus rien ; une autre langue ne
  le reçoit pas.

**Ne pas toucher :** les fichiers de la barrière de PL-01, laissés non commités dans l'arbre
(`HydrationMarker.tsx` des deux fronts, `e2e/support/hydration.ts`, `e2e/support/journey.ts`, les
deux layouts racines, `backoffice-auth-screens.spec.ts`, `security-headers.spec.ts`) : ni modifiés
ni indexés. Aucune assertion de `journey-resume.spec.ts` ; aucun `retries`, `timeout`,
`waitForTimeout`. Aucun contrat de `/v1/auth/journey`.

**Prouver :** `pnpm check:fast` ; tests unitaires ci-dessus ; `journey-resume.spec.ts` vert **cinq
invocations séparées de suite**, configuration par défaut (2 workers),
`pnpm --filter @influx/web exec playwright test journey-resume.spec.ts --reporter=line` (pas de
`--repeat-each` : adresses fixes par passage, limiteur des demandes de code).

**Arrêt si :** le correctif exige de changer l'API du parcours ou un autre appelant de
`journey-memory.ts` que `AuthFlow` ; l'intermittent persiste après le correctif (décrire la trace).
