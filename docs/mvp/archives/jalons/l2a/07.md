# L2A-07 — `test: no name or handle in a connected-space path`
Grille `dev-react-node` (J4S-7, sécurité).
**Lire :** fiche § Lectures (ligne 07).
**Livrer :**
- Garde dans `packages/test-kit` : échec si une page ou une route de `apps/web/src/app/[locale]/(member)/`
  ou de `apps/backoffice/src/app/(app)/` porte un segment dynamique hors d'une liste fermée commentée
  (`[id]` = identifiant opaque, UUID) ; échec si une valeur de `MEMBER_PAGE_SLUGS` n'est pas un
  littéral de lettres, chiffres, `-` et `/`.
- Message d'échec : « segment = identifiant opaque, ou modèle de route Next envoyé par le collecteur
  (`error-collector.ts` l. 42) ».
- Cas négatif sur un arbre témoin (`[handle]`, `[alias]`).
**Ne pas toucher :** collecteur, routes, pages.
**Prouver :** cas de la garde côté test-kit, web et backoffice ; planchers relevés ;
`pnpm check:fast`.
**Arrêt si :** une route existante enfreint déjà la règle (la nommer).
