# L2E-04 — Arbitrage : socle des sources de registre
Grille `expert-integrations-api`. Aucun code.
**Lire :** `06` l. 419-427 ; `decisions-detail.md` D79 point 12 ; `reference.countries` (`0201`).
**Livrer :** `docs/mvp/jalons/l2e/registres.md` (≤ 6 Ko), table `pays ISO | source | URL | type (national, e-Justice, GLEIF) | gratuit (oui) | relevé le` :
- Les 27 pays de l'Union par le portail e-Justice, puis Royaume-Uni, Suisse, Norvège, États-Unis, Canada, Australie, Nouvelle-Zélande, Japon, Corée, Singapour, Émirats, Brésil, Mexique, Inde, Maroc, Afrique du Sud, si une source admise existe ;
- La base mondiale GLEIF, source de repli de tout pays ;
- Pour chaque ligne, **page ouverte** et date du relevé ; registre payant à l'acte, agrégateur privé ou certificat de la marque : exclus (D79) ; pays sans source : listé à part, avec la raison.
**Ne pas toucher :** migrations ; aucune clé ni inscription à un service.
**Prouver :** URL réellement lues, une ligne d'écart par source non admise.
**Arrêt si :** aucune source n'est gratuite pour un grand marché visé : à dire au fondateur, sans l'inventer. États-Unis : registres par État, indiquer la conduite retenue (GLEIF ou liste d'États).
