## Décisions sur les quatre points remontés

1. **Refus d'un code faux affiché deux fois** : défaut réel, mais sans effet sur la décision (la base refuse). L2EU-10, avant production. Le texte `refusedNotice` est bien celui de la marque.
2. **Backoffice français seul** : non bloquant, L2EU-16, plus tard.
3. **Lien « Ouvrir »** : L2EU-11, avant production.
4. **EC-L2E-23-2** : approuvé tel quel, un seul ajout de libellé (L2EU-12).
