## 1. Les huit points
1. **Dépôt.** Suivie : relais généralisé, E1 écarté ; plafond par chemin, `reencodeEvidence()`, lecture JSON, portfolio : D82.
2. **États.** Suivis : `draft`, `pending`, `approved`, `rejected`, `cancelled`, `expired`, `closed` ; « à réexaminer » : motif interne, `pending` gardé. File : `pending` seul.
3. **Propriétaires.** Corrigée, trois : `influx_verification_definer` (neuf : décisions, lecture de pièce), `influx_creator_verification_definer` (neuf : portes créateur), `influx_identity_definer` (portes marque, dans `profiles`, sans droit sur les pièces : -18).
4. **Chiffres (L2DS-2).** Suivie : `creator_social_accounts` = le déclaré (`figures_source = 'declared'` contraint) ; ligne publique dérivée du badge d'audience tenant (`active`, `to_refresh`), sinon du déclaré ; `figures_measured_at` = `granted_at` ; `reach_band` toujours déclarée (RG39). Lot 4 : révélation lue du badge tenant.
5. **Bloc interne.** Suivi : `profiles.advertiser_internal_details` ; `legal_name` gardé, commenté « nom commercial ». 6. **Paramètres** : `backoffice.operational_settings` (§4).
7. **Brevo.** Suivie : `VERIFIED_LEVEL` `none` · `n1` (compte ou marque) · `n2` (audience) ; `VERIFIED_AT` : date du badge qui fixe le niveau.
8. **Adresses** : §6.

## 3. Schéma `verification` (0221 sauf mention)
Énums `badge_level` (`account_verified`, `audience_verified`, `brand_verified`), `request_status`, `badge_state` (`active`, `to_refresh`, `to_reconfirm`, `expired`, `revoked`, `replaced`), `evidence_state` (`pending`, `active`, `purging`, `purged`).
- **`verification_requests`** : `id`, `account_id` (FK `identity.accounts`), `social_account_id` (nul ⇔ marque ; sans FK : la trace survit à la ligne), `network_code`, `level`, `population` (générée `creator`, `brand`), `status`, `created_at`, `submitted_at`, puis les colonnes d'échéance, de prise, de levée et de décision de `file.md` A1 (`sla_due_at`, `escalate_at` figés à la soumission ; `sla_breached` générée) ; `rejection_reason_code` (FK `(population, code)`), `member_message`, `internal_comment`, `reexamine_reason_code` (`network_unreachable`, `evidence_technical`, `registry_unavailable`, `storage_unavailable`), `reexamined_at`, `escalated_at`, `cancelled_at`, `updated_at`. `closed` ⇔ motif `account_unavailable`. Un `draft` ou `pending` par `(account_id, coalesce(social_account_id, nil), level)`.
- **`ownership_codes`** : `id`, `request_id`, `account_id`, `kind` (`network`, `domain`), `code` unique (`INFLUX-` + 8 de `23456789ABCDEFGHJKMNPQRSTUVWXYZ`, `gen_random_bytes`, octets ≥ 248 rejetés), `created_at`, `expires_at`, `revoked_at`, `observed_by_account_id`, `observed_at`, `observed_handle`, `observed_platform_account_ref`, `observed_domain`, `observed_channel` (`dns_txt`, `web_page`). Un non révoqué par demande ; `observed_at` ⇔ handle (`network`) ou domaine et canal (`domain`).
- **`evidence_files`** (lignes 0221, cycle 0223) : colonnes de `brand_logo_objects` (0204 ; compte vers `creator_public_profiles`, bornes de D82), plus `request_id`, `checksum` (sha256 du WebP), `retention_due_at` NOT NULL, `deleted_at` (⇔ `purged`) ; `object_key` générée `<account_id>/<request_id>/<id>.webp`.
- **`badges`** : `04` l. 1591 (`_agent_id` → `_account_id`), plus `network_code`, `request_id`, `registry_source_id`, `observed_posts_last_30_days`, `observed_avg_comments`, `declared_posts_at_decision`, `declared_comments_at_decision` ; `observed_engagement` → `observed_engagement_bp` (0-10 000), `declared_engagement_bp_at_decision` ; `evidence_source` : `public_profile`, `native_dashboard`, `domain_and_registry`. Audience ⇒ trois chiffres, période, `expires_at`.
- **`rejection_reasons`** : PK `(population, code)`, `label_key` `reason.verification.<code>`, `message_key` `verificationDecision.reason.<population>.<code>`, `requires_member_message` (`other`, `terms_breach`), `escalates_to_admin` (RG59), `purges_evidence` (`evidence_too_wide`), `position`, `is_active`. **`revocation_reasons`** : `04` l. 1629.
- **`registry_sources`** : `id`, `country_code` (nul : GLEIF), `source_type` (`national`, `e_justice`, `gleif`), `name`, `url` (`https://`), `checked_on`, `is_active`, `updated_by_account_id`, `updated_at` ; une active par pays.
- **`profiles.advertiser_internal_details`** (0222) : `account_id`, `legal_name` ≤ 160, `registration_country_code`, `registration_number` ≤ 40, dates.

Lecture : créateur, ses lignes, sans prise, agent, commentaire, réexamen, escalade, constat, clé ni empreinte ; marque : sa fonction de lecture ; `agent`, `admin` : `aal2`, hors compte propre, sans `object_key` ; annonceur : rien.
